# Agent instructions

## Start here

Read the [engineering guidelines](skills/langonrock/reference/engineering-guidelines.md)
before working in this repository. They preserve the project's existing rules
and apply to every task.

Use the [langonrock project skill](skills/langonrock/SKILL.md) to select a workflow.
The [project manual](skills/langonrock/README.html) provides a browsable version.
